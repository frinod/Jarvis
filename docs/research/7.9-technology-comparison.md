## 2. Technologies Considered and Rejected

| Technology | Reason for rejection |
|------------|---------------------|
| Graph RAG (Microsoft GraphRAG) | Requires knowledge graph infrastructure; low value at Phase 7 corpus size |
| Hierarchical RAG (RAPTOR) | Valuable for long documents; Phase 7 corpus is short entries |
| Weaviate | Docker required for development; violates offline-first constraint |
| Pinecone | Cloud-only; violates offline-first constraint |
| `all-mpnet-base-v2` | 420 MB — too large for development machine |
| Self-Consistency CoT | 3–5× LLM calls per request; cost/latency unacceptable for trading assistant |
| Tree of Thoughts | Requires parallel execution infrastructure not yet built |
| DSPy | Requires labelled outcome dataset that does not yet exist |
| MCP protocol | External client exposure not in Phase 7 scope |
| RLHF | Requires fine-tunable model; API providers not fine-tunable |
| LSTM / Transformer forecasting | No training data pipeline; existing XGBoost models sufficient |
| VADER / RoBERTa sentiment | Existing API sentiment field is sufficient for Phase 7 |
| Counterfactual XAI | High complexity; SHAP is sufficient for Phase 7 |

## 4. Recommended Implementation Phases

### Phase 7A — Foundation (Memory + RAG)
*Prerequisite for everything else.*

1. `QdrantLongTermMemory` + `SentenceTransformerEmbeddingService`
2. Hybrid retrieval (Qdrant sparse + dense)
3. `ReRanker` ABC + `CrossEncoderReRanker`
4. `SemanticCache`
5. Metadata filtering (`entry_type`)
6. Token-budgeted context injection

**Gate**: all 1517 existing tests pass + new Phase 7A tests pass.

### Phase 7B — Prediction + Market Intelligence
*Depends on 7A (perception data stored to LTM).*

1. `TechnicalFeatureExtractor`
2. `XGBoostForecastingEngine`
3. `AngelOneMarketPerception` + `LiveNewsPerception`
4. `MarketEvent` detection
5. Perception-to-LTM pipeline

**Gate**: `TraderAgent` produces real predictions for covered symbols.

### Phase 7C — Agent Framework + Reasoning
*Depends on 7A and 7B.*

1. `ReactExecutor`
2. `AIToolRegistry.to_schema()` (native function calling)
3. Parallel `WorkflowEngine` (`asyncio.gather()`)
4. Sequential result handoff between nodes
5. `CapabilityMatchPolicy` intent fix
6. `LLMReasonerAdapter` (LLM-generated CoT)
7. `LLMPlannerAdapter` (LLM intent classification)
8. LLM self-critique loop

**Gate**: `AnalystAgent` and `TraderAgent` produce real LLM-reasoned responses.

### Phase 7D — XAI + Learning Infrastructure
*Depends on 7B and 7C.*

1. SHAP in `XGBoostForecastingEngine`
2. Confidence decomposition in responses
3. NL explanation via `BaseAgent.explain()`
4. Decision trace API endpoint
5. `OutcomeRecord` + `ActionItemExecutor`
6. In-context learning (example storage + retrieval)

**Gate**: trade signals include SHAP rationale; decision trace endpoint works.
