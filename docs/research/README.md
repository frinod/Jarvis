# JARVIS Phase 7 — Research Library

## Purpose

Each document in this library covers one research topic for Phase 7.
Documents are independently reviewable and limited to ~150–300 lines.
After all documents are approved, `docs/architecture/phase7-architecture.md`
will reference them instead of repeating their content.

## Workflow

1. Each document is written, then reviewed and approved before the next begins.
2. ADRs in `docs/adr/` record every significant architectural decision with rationale.
3. `docs/architecture/phase7-architecture.md` is written last, referencing these documents.
