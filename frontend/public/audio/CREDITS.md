# Audio Overrides

Drop MP3 files here to replace the synthesised cues:

## Sound Effects (synthesised by default — no files needed)
- `boot.mp3`   — reactor spin-up sound
- `wake.mp3`   — wake word detected ping
- `listen.mp3` — listening mode pip
- `tool.mp3`   — tool execution tick
- `done.mp3`   — turn complete chime
- `error.mp3`  — error tone

## Music Score (silent by default — add files for music)
- `boot-music.mp3` — plays once during boot sequence (recommended: ~17s)
- `ambient.mp3`    — plays once alongside boot (background swell)
- `work.mp3`       — loops while a tool/query is running
